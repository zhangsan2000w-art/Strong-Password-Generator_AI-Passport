# 安全说明

[English](SECURITY.md) | 简体中文

## 安全目标

生成的密码必须来自适合密码用途的设备随机源；只有用户明确选择“发送”后才允许离开设备。固件只把 BLE 初始化为 HID 键盘，不初始化 Wi-Fi 或 NFC，不记录密码日志与历史，不把密码写入 NVS，也不提供剪贴板或屏幕截图传输路径。

## 随机数设计

ESP-IDF 文档说明，只有 RF 或 bootloader random source 等熵源处于活动状态时，`esp_random()`／`esp_fill_random()` 才提供真随机数。AI Passport 按键使用 ADC 电阻梯，因此平台适配器会在 `bsp_button_init()` 占用 ADC1 前执行：

1. 创建并初始化 Mbed TLS CTR-DRBG 上下文。
2. 启用 ESP-IDF bootloader random 熵源。
3. 通过 `esp_fill_random()` 熵回调和固定 personalization 字符串为 DRBG 播种。
4. 在初始化 ADC 按键驱动前关闭 bootloader 熵源。
5. 使用互斥锁保护的 DRBG 响应生成请求。

Personalization 字符串用于公开的域分离，不是秘密或固定种子。实现不使用 `rand()`、时间戳、`millis()`、固定 seed 或应用层 LCG。

MoonBit 通过回调取得随机数。主机测试将其替换为 `DeterministicSource`；该测试源和主机 C stub 不进入固件生成。

## 无偏映射与策略

MoonBit 核心在取模前使用拒绝采样，丢弃最高处不完整桶内的采样，因此字符和词库索引不会因直接取模而产生偏差。

Random 密码始终包含字母。开启数字或符号后，算法先从每个启用类别生成至少一个字符，再执行 Fisher–Yates 洗牌。PIN 只接受 `0`～`9`。Passphrase 索引按词库数量检查，生成的 C 词库接口也会检查每个索引和字符偏移。

## 敏感数据生命周期

C 显示缓冲固定为 128 字节，只接受可显示 ASCII，并在重新生成前、配置变化后及输出失败时使用 `mbedtls_platform_zeroize()` 擦除。生成器不会把内容输出到 ESP 日志。

BLE 发送只把当前结果复制到一个固定大小的队列项。后台任务逐个发送按键按下／释放 HID report，并在本次尝试结束后清零队列项与 report 缓冲。NVS 最多只持久化 BLE bond key 和对端身份元数据，生成密码不会进入 bond 记录。

当前 MoonBit native runtime 没有为所有临时对象提供可依赖的显式安全擦除保证。Random 生成过程使用临时 `FixedArray`，优化器或 runtime 副本可能保留到内存被复用。这是已记录限制：固件会降低明显残留，但不声称能够完全抵抗 RAM 取证。

结果显示期间，LVGL 也会在自身对象内存中保留标签文本。新结果或参数变化会替换可见内容，但 V1 不声称每一份 LVGL 内部分配都会立即擦除。

## 失败行为

如果 RNG 初始化、互斥锁获取、DRBG 生成、输出边界或词库访问失败，适配器会擦除结果，UI 显示“生成失败 请重试”。它不会退化为时间戳、可预测序列或看起来像密码的占位值。

## BLE 键盘边界

- 设备以 `FoloPassKey` 广播，只接受一个 BLE 连接。
- 首次配对使用无需配对码的绑定式 Just Works。连接仍会加密，但不具备中间人认证；只有加密成功且主机订阅键盘输入 report 后，“发送”才可用。
- 只有用户把焦点移到“发送”并按 `OK` 后才会传输；生成动作不会自动输入。
- 最多保留 3 个 BLE bond，便于已知主机重连。当前尚无设备端 bond 管理页，删除配对需在电脑／手机的蓝牙设置中完成。
- HID usage 按美式键盘布局映射。要准确输入符号，主机必须切到英文直接输入；中文输入法或其他键盘布局可能转换收到的按键。
- 输入完成后，文本由目标应用和操作系统管理。浏览器表单历史、剪贴板管理器、辅助功能、录屏或焦点落错输入框造成的暴露不在设备控制范围内。

## 不作出的安全承诺

- 屏幕熵值是根据配置搜索空间计算的估算，不是针对网站策略或泄露密码库的强度审计。
- 主机测试或固件构建成功，不能证明物理 RNG 质量、屏幕隐私、侧信道防护或设备防拆能力。
- 固件只提供一次性的、由用户确认的 BLE 键盘传输，不提供密码存储、恢复、同步或管理。

## 仍需真机验收

- 多次冷启动与生成不会报告 RNG 失败。
- Random 模式包含全部已开启字符类别，所有输出可正常阅读。
- 串口控制台不出现生成值。
- 参数变化会替换此前屏幕结果。
- Wi-Fi、NFC 保持未启用，系统电源键行为不变。
- 在可用的 Windows、Android 与 iOS 主机上配对 `FoloPassKey`，确认主机不要求输入配对码，并验证重连、断开后重新广播以及重启后的 bond 持久化。
- 主机切到英文直接输入，在有意聚焦的非敏感测试输入框中确认每个生成字符只输入一次，并确认串口日志始终没有密码。
- 在目标硬件上确认休眠／唤醒和低电量行为。
